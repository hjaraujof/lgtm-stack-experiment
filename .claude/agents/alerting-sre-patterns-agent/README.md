# Alerting and SRE Patterns Agent

Research agent for alerting design, SLO/SLI patterns, and SRE best practices.

## Scope

- Alert rule design (LogQL, PromQL)
- SLO/SLI definition and error budgets
- Multi-window, multi-burn-rate alerting
- Notification routing and escalation
- Recording rules and alert fatigue prevention

## When to Invoke

- Designing alert rules
- Defining SLOs for services
- Setting up notification channels
- Reviewing alert quality
- Planning error budget tracking
