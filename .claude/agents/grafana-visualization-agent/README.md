# Grafana Visualization Agent

Research agent for Grafana dashboard design, datasource configuration, and alerting patterns.

## Scope

- Dashboard design patterns and best practices
- Datasource configuration (Loki, Tempo, Mimir)
- Cross-signal correlation setup (trace-to-logs, exemplars)
- Alerting configuration and notification channels
- Visualization techniques for observability data

## When to Invoke

- Designing new dashboards
- Configuring datasource correlation
- Setting up alerting
- Troubleshooting visualization issues
- Optimizing Grafana performance
