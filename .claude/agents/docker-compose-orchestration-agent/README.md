# Docker Compose Orchestration Agent

Research agent for Docker Compose orchestration patterns and container management.

## Scope

- Service orchestration and dependency management
- Health checks and startup ordering
- Volume management and permissions
- Network configuration and service discovery
- Resource limits and restart policies

## When to Invoke

- Troubleshooting startup issues
- Adding new services to the stack
- Optimizing container resources
- Configuring health checks
- Debugging networking problems
