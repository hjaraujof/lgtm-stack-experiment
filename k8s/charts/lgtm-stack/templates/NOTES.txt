LGTM stack installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

Wait for it, then prove it:

  kubectl -n {{ .Release.Namespace }} rollout status sts/mimir --timeout=300s
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

Reach it:

  Grafana   https://{{ .Values.ingress.host }}{{ if not .Values.ingress.enabled }}  (ingress disabled - use port-forward){{ end }}
            user {{ .Values.grafana.adminUser }}
  OTLP      otel-collector.{{ .Release.Namespace }}.svc.cluster.local:4318  (from inside the cluster)

From outside the cluster, forward a port rather than exposing a Service:

  kubectl -n {{ .Release.Namespace }} port-forward svc/otel-collector 4318:4318
  ./scripts/send-test-telemetry.sh

{{- if not .Values.secretsStore.enabled }}

The admin password was GENERATED by k8s/scripts/create-secrets.sh and is written nowhere.
Read it back with:

  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.grafana.credentialsSecret }} \
    -o jsonpath='{.data.admin-password}' | base64 -d
{{- end }}
{{- if .Values.minio.enabled }}

MinIO holds the local object storage. Its root credentials are a generated Kubernetes
Secret, which is base64 and NOT encryption. That is acceptable for a throwaway cluster and
is not acceptable anywhere else: values-eks.yaml turns MinIO off and gives Tempo and Mimir
an AWS identity instead of a key.
{{- end }}

with no public DNS.
{{- end }}
